# Changelog

## 0.1.0 — 2026-09-08

- Laravel 12 and 13 support.
- Separate web and app authorization scopes with database-enforced grant isolation.
- Modules with optional submodules; direct and nested permissions can coexist.
- Single-role replacement and multiple-role assignment, independently per scope.
- Configurable single-role enforcement through the assignment API.
- Transactional assignment updates and explicit scope-aware Gate abilities.
- Publishable migrations/configuration and automatic provider discovery.
- Permission revocation, active-role checks and relational integrity.
- Documentation linking the author's original Medium article.
